![](../../../Assets/Pasted%20image%2020261027144829.png)**Four statements are true of a UDP socket: the first, fifth, sixth, and seventh.**

1. **True.** A UDP server uses a single socket to receive datagrams from any number of clients. Each received datagram comes with the sender's address.
2. **False.** Reliable, in-order byte-stream transfer is what TCP provides.
3. **False.** Creating a new server-side socket per client is TCP behavior: the welcoming socket's `accept()` returns a new connection socket for each client.
4. **False.** `socket(AF_INET, SOCK_STREAM)` creates a TCP socket.
5. **True.** UDP provides unreliable transfer of groups of bytes (datagrams), with no guarantee of delivery or ordering.
6. **True.** UDP has no connection, so the application must give the destination IP address and port number with each datagram it sends, for example with `sendto()`.
7. **True.** `socket(AF_INET, SOCK_DGRAM)` creates a UDP socket.
8. **False.** `accept()` is used only on TCP sockets, because it completes a connection setup. UDP has no connections.
