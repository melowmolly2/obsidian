# Phần 2.3 – Email, SMTP, IMAP

Nội dung từ slide bài giảng của GS. Jim Kurose (UMass), chương **Application Layer**.

---

### 1. Ba thành phần chính của E-mail

| Thành phần | Vai trò |
|---|---|
| **User Agent (UA)** | "Mail reader" – soạn, đọc, chỉnh sửa mail (VD: Outlook, iPhone Mail) |
| **Mail Server** | Lưu mailbox, hàng đợi gửi, giao tiếp qua SMTP |
| **SMTP** | Giao thức truyền mail giữa các server |

---

### 2. SMTP (RFC 5321)

- Dùng **TCP**, cổng **25**
- **Client push** (khác HTTP là client pull)
- Lệnh: ASCII text → Response: status code + phrase
- Message phải là **7-bit ASCII**
- Kết thúc message: `CRLF.CRLF`
- Dùng **persistent connections**

**Ba giai đoạn:**
1. SMTP Handshaking (greeting)
2. SMTP Transfer of messages
3. SMTP Closure

---

### 3. Kịch bản Alice gửi mail cho Bob

1. Alice dùng UA soạn mail đến `bob@someschool.edu`
2. UA gửi mail lên **mail server của Alice** qua SMTP → vào message queue
3. SMTP client tại mail server Alice mở **TCP connection** với mail server của Bob
4. SMTP client gửi message qua TCP
5. Mail server Bob đặt message vào **mailbox của Bob**
6. Bob dùng UA để đọc

---

### 4. Ví dụ SMTP interaction

```
S: 220 hamburger.edu
C: HELO crepes.fr
S: 250 Hello crepes.fr, pleased to meet you
C: MAIL FROM: <alice@crepes.fr>
S: 250 alice@crepes.fr... Sender ok
C: RCPT TO: <bob@hamburger.edu>
S: 250 bob@hamburger.edu... Recipient ok
C: DATA
S: 354 Enter mail, end with "." on a line by itself
C: Do you like ketchup?
C: How about pickles?
C: .
S: 250 Message accepted for delivery
C: QUIT
S: 221 hamburger.edu closing connection
```

---

### 5. So sánh SMTP vs HTTP

| Tiêu chí | HTTP | SMTP |
|---|---|---|
| Kiểu | Client **pull** | Client **push** |
| Giao diện | ASCII command/response | ASCII command/response |
| Object | Mỗi object trong 1 response | Nhiều object trong 1 multipart message |

---

### 6. Định dạng mail (RFC 2822)

- **Header**: `To:`, `From:`, `Subject:` (khác với lệnh SMTP `MAIL FROM`, `RCPT TO`)
- **Blank line** ngăn cách header và body
- **Body**: ASCII characters only

---

### 7. Giao thức truy xuất mail

$$\text{Sender UA} \xrightarrow{\text{SMTP}} \text{Sender Server} \xrightarrow{\text{SMTP}} \text{Receiver Server} \xrightarrow{\text{IMAP/HTTP}} \text{Receiver UA}$$

- **SMTP**: gửi/lưu mail lên server
- **IMAP** (RFC 3501): truy xuất, xóa, quản lý folder trên server
- **HTTP**: webmail (Gmail, Yahoo...) = giao diện web trên SMTP + IMAP/POP

---

**Tóm tắt:** Email hoạt động qua 3 lớp – UA soạn thảo, SMTP đẩy mail giữa các server, IMAP/HTTP để người nhận lấy mail về.
