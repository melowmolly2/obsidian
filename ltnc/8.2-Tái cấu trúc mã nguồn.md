## Code smell
- Code smells are usually not bugs
- Identify design deficeincies that negatively impact development speed and elevate the risk of bugs or system failures
- Kind of code smells
	- Condition & Parameter
	- Method
	- Field
	- Class/interface
## Refactoring
- Refactoring (noun): a change made to the internal structure of software to make it easier to understand and cheaper to modify without changing its observable behavior
