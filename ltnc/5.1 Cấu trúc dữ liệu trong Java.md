# 📚 Cấu trúc dữ liệu trong Java – Tóm tắt lý thuyết

---

## 1. Lớp `Object`

- **Lớp cha** của tất cả các lớp đối tượng trong Java.
- Các phương thức phổ biến:
  - `getClass()` – trả lại lớp của đối tượng hiện tại.
  - `equals(Object obj)` – so sánh hai đối tượng (thường được **override** lại).
  - `toString()` – biểu diễn đối tượng dưới dạng chuỗi.

---

## 2. Lớp Wrapper

Dùng để **bọc kiểu dữ liệu nguyên thủy** thành đối tượng.

| Nguyên thủy | Wrapper |
|---|---|
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `boolean` | `Boolean` |
| `char` | `Character` |

### Lớp `Integer`
- `Integer.valueOf("12")` – chuyển String → Integer
- `intValue()` – lấy giá trị `int`
- `Integer.parseInt("12")` – chuyển String → `int`
- `Integer.MAX_VALUE` = 2³¹ − 1; `Integer.MIN_VALUE` = −2³¹

### Lớp `Character`
- `isUppercase(ch)`, `isLowercase(ch)`, `isDigit(ch)` – kiểm tra ký tự.

---

## 3. Lớp `String`

- **Bất biến (immutable)**: mọi thao tác chỉnh sửa đều tạo ra bản sao mới.
- Các phương thức phổ biến:
  - `length()` – độ dài chuỗi
  - `charAt(int index)` – ký tự tại vị trí index
  - `equals()` / `equalsIgnoreCase()` – so sánh chuỗi
  - `toUpperCase()` / `toLowerCase()`
  - `concat(String s)` hoặc dùng `+`
  - `indexOf(String str)` – tìm từ trái sang phải
  - `lastIndexOf(String str)` – tìm từ phải sang trái
  - `replace(char old, char new)` – thay thế ký tự
  - `trim()` – xóa khoảng trắng đầu/cuối
  - `substring(int startIndex)` – cắt chuỗi từ vị trí

---

## 4. Lớp `StringBuffer`

- Lưu chuỗi ký tự **có thể chỉnh sửa trực tiếp** (không tạo bản sao).
- Phù hợp khi cần thao tác nhiều trên chuỗi dài.
- Khởi tạo: `new StringBuffer()` (kích thước mặc định 16), `new StringBuffer(String)`, `new StringBuffer(int length)`

---

## 5. Lớp `Math`

Cung cấp các hàm toán học tĩnh:
- `Math.abs()`, `Math.sqrt()`, `Math.pow()`, `Math.max()`, `Math.min()`, `Math.random()`, v.v.

---

## 6. Mảng & Lớp `Arrays`

- Kích thước mảng **cố định** khi khởi tạo.
- Lớp `Arrays` cung cấp các tiện ích:
  - `Arrays.sort(arr)` – sắp xếp mảng
  - `Arrays.binarySearch(arr, key)` – tìm kiếm nhị phân (**phải sắp xếp trước**)

## 7. Giao diện `Collection` và các lớp con

Cây thừa kế:
```
Collection
 ├── List       → ArrayList, LinkedList, Stack
 ├── Set        → HashSet, TreeSet (SortedSet)
 └── Queue      → Deque → LinkedList
```

### `List` – danh sách có thứ tự, truy cập theo chỉ số
### `ArrayList`
- Linh hoạt hơn mảng (kích thước không cố định)
- `add(E)`, `get(int index)`, `remove(int index)`, `size()`

### `Stack` (LIFO – Last In First Out)
- `push(E)` – thêm vào đỉnh
- `pop()` – lấy ra từ đỉnh

### `HashSet` / `TreeSet` (Set – không có phần tử trùng)
- `add(E)`, `contains(E)`, `remove(E)`
- `TreeSet` lưu theo thứ tự sắp xếp

### `Queue` (FIFO – First In First Out)
- `add(E)` – thêm vào hàng đợi
- `poll()` – lấy và xóa phần tử đầu

### `Deque` – hàng đợi hai đầu
- `addFirst()`, `addLast()`, `pollFirst()`, `pollLast()`

### `LinkedList`
- Cài đặt cả `List` lẫn `Queue`/`Deque`

## 8. Giao diện `Iterator`

Duyệt và xóa phần tử trong khi duyệt tập hợp:
- `hasNext()` – còn phần tử kế tiếp?
- `next()` – lấy phần tử kế tiếp
- `remove()` – xóa phần tử vừa lấy

```java
Iterator i = list.iterator();
while (i.hasNext()) {
    System.out.println(i.next());
}
```

## 9. Giao diện `Map` và các lớp con

Lưu các cặp **(key, value)** – không có hai key giống nhau.

Cây thừa kế:
```
Map
 ├── HashMap
 ├── HashTable
 └── SortedMap → TreeMap
```

### `HashMap`
- Tìm kiếm **tức thì** theo key (không cần vòng lặp) → hiệu quả hơn `ArrayList` khi dữ liệu lớn.
- `put(key, value)` – thêm phần tử
- `get(key)` – lấy giá trị theo key

**Ví dụ so sánh tìm sách theo ISBN:**
- Dùng `ArrayList`: phải lặp qua từng phần tử → chậm khi dữ liệu lớn.
- Dùng `HashMap`: truy cập trực tiếp `allBooks.get(isbn)` → **nhanh hơn đáng kể**.

## 🔑 Tổng kết

| Cấu trúc | Đặc điểm chính |
|---|---|
| `ArrayList` | Danh sách có thứ tự, truy cập theo chỉ số |
| `Stack` | LIFO |
| `Queue` / `LinkedList` | FIFO |
| `HashSet` | Không trùng lặp, không có thứ tự |
| `TreeSet` | Không trùng lặp, có thứ tự sắp xếp |
| `HashMap` | Cặp key-value, tìm kiếm nhanh |

> Hiểu rõ đặc điểm từng cấu trúc dữ liệu giúp **lựa chọn đúng** khi lập trình, từ đó tối ưu hiệu năng chương trình.
