# Object
- Lớp `Object` là lớp cha của tất cả các lớp đối tượng trong Java.
![](../Assets/Pasted%20image%2020260529162704.png)
## Các phương thức phổ biến
- Class `getClass()`: trả lại lớp của đối tượng hiện tại
```Java
Cat a = new Cat("Tom");
Class c = a.getClass(); 
System.out.println(c); //"Cat" 
```
- `boolean.equals(Object obj)`: Trả về `true` nếu đối tượng gọi hàm `equal` "bằng" đối tuognwj `obj`, ngược lại trả về false
	- Phương thức này thường định nghĩa lại (override) cho phù hợp với tiêu chí so sánh
- `String toString()`: trả lại biểu diễn của đối tượng dưới dạng xâu ký tự
# Lớp Wrapper
## Định nghĩa
- Lớp wrapper (wrapper class), còn được gọi là lớp gói, được dùng để bọc một kiểu dữ liệu nguyên thủy sao cho trông như một đo
