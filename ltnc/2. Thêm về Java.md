## 1. Cấu trúc chương trình Java

- Tập lớp, mỗi lớp một file `.java` (tên file = tên lớp)
- Mọi câu lệnh đều nằm trong một lớp (trừ `import`)
- Tăng tính mô-đun, dễ sửa đổi, giảm thời gian biên dịch

```java
// GradeBook.java
public class GradeBook {
    public void displayMessage() {
        System.out.println("Welcome to the Grade Book!");
    }
}

// GradeBookTest.java
public class GradeBookTest {
    public static void main(String args[]) {
        GradeBook myGradeBook = new GradeBook(); // tạo đối tượng
        myGradeBook.displayMessage();             // gọi phương thức
    }
}
```

## 2. Kiểm soát truy cập (Access Control)

| Modifier | Phạm vi |
|---|---|
| `public` | Truy cập từ bất kỳ đâu |
| `protected` | Lớp đó, lớp con, cùng package |
| `private` | Chỉ nội bộ lớp đó |

> **Best practice**: Thuộc tính dùng `private`, phương thức truy cập qua **getter/setter** `public`.

## 3. Nạp chồng phương thức (Method Overloading)

Cùng tên, khác danh sách tham số:

```java
class MyDate {
    public boolean setMonth(int m)    { ... }
    public boolean setMonth(String s) { ... }
}
d.setMonth(9);
d.setMonth("September");
```

## 4. Constructor (Phương thức khởi tạo)

- Tên **trùng** tên lớp, **không có** kiểu trả về
- Tự động gọi sau `new`
- Nếu không khai báo → JVM cung cấp constructor rỗng mặc định

| Loại | Ví dụ |
|---|---|
| Không tham số (mặc định) | `new MyDate()` |
| Có tham số | `new MyDate(19, 9, 2014)` |
| Copy constructor | `new MyDate(d)` – sao chép từ đối tượng khác |

```java
class MyDate {
    private int day, month, year;

    public MyDate() { day=1; month=1; year=2014; }

    public MyDate(int d, int m, int y) { day=d; month=m; year=y; }

    public MyDate(MyDate d) {  // copy constructor
        year=d.year; month=d.month; day=d.day;
    }
}
```

> ⚠️ Nếu khai báo constructor có tham số mà **không khai báo** constructor rỗng → `new MyDate()` sẽ **lỗi biên dịch**.

## 7. Toán tử `new` & phép gán =

### `new` – cấp phát Heap
```java
MyDate d;          // chỉ là tham chiếu, chưa có đối tượng
d = new MyDate();  // tạo đối tượng trên Heap
```

### = – sao chép tham chiếu, KHÔNG sao chép đối tượng!
```java
Integer m = new Integer(10);
Integer n = new Integer(20);
m = n;            // m và n cùng trỏ đến đối tượng 20
n.setValue(50);
System.out.print(m); // → 50  (vì m và n là cùng đối tượng!)
```

## 8. So sánh == vs `.equals()`

|             | ==                                 | `.equals()`          |
| ----------- | ---------------------------------- | -------------------- |
| Nguyên thủy | So sánh giá trị ✅                  | —                    |
| Đối tượng   | So sánh **địa chỉ** (cùng object?) | So sánh **nội dung** |

```java
Integer m1 = new Integer(10);
Integer m2 = new Integer(10);
m1 == m2        // false  (2 object khác nhau trên Heap)
m1.equals(m2)   // true   (nội dung bằng nhau)
```

> Với class tự định nghĩa: phải **override** `equals()`, nếu không mặc định trả `false`.

## 9. Garbage Collection (Thu hồi bộ nhớ)

- Lập trình viên **không cần** `free()` / `delete`
- JVM tự thu hồi đối tượng khi **số tham chiếu trỏ tới = 0**
- Không đảm bảo thời điểm chính xác GC chạy
- Lợi ích: không bao giờ "quên giải phóng bộ nhớ"

```java
MyDate openDate = new MyDate(2,9,2019);
MyDate startDate = new MyDate(10,10,2020);
openDate = startDate; // object 2-9-2019 không còn tham chiếu → GC thu hồi
```

## 10. Package (Gói)

- Nhóm các lớp liên quan, tránh xung đột tên
- **Khai báo**: `package dse.hello;` (đầu file)
- **Sử dụng**: 2 cách

```java
// Cách 1: import một lần
import dse.hello.Hello;
Hello h = new Hello();

// Cách 2: chỉ rõ mỗi lần dùng
dse.hello.Hello h = new dse.hello.Hello();
```

**Biên dịch & chạy với package:**
```
javac dse/test/HelloTestDrive.java
java dse.test.HelloTestDrive
```

## 11. Hợp thành (Composition)

Quan hệ **"has-a"**: đối tượng chứa đối tượng khác làm thuộc tính.

```java
public class Person {
    private String name;
    private MyDate birthday;  // hợp thành

    public Person(String s, MyDate d) {
        name = s;
        birthday = new MyDate(d); // dùng copy constructor để tránh aliasing
    }

    public MyDate getBirthday() {
        return new MyDate(birthday); // trả bản sao, không trả tham chiếu gốc
    }
}
```

> ⚠️ Nên **trả bản sao** (copy) thay vì tham chiếu gốc để bảo vệ tính bao gói (encapsulation). Nếu trả tham chiếu gốc, bên ngoài có thể sửa thuộc tính `private` thông qua nó.
