# Gòm 3 phần: 
- Phần đầu: Gồm tên class (bắt buộc)
- Phần giữa: Gồm thuộc tính class
- Phần cuối: Gồm method
## Member access modifiers
All classes have differenet access levels depending on the access modifier (visibility):
- Public (+)
- Private (-)
- Protected (#)
- Package (-)
- Derived (/)
- Static (underlined)
