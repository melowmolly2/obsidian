# Lý thuyết Tuần 1 – Hệ sinh thái Java & Tư duy hướng đối tượng

---

## 1. Lịch sử & Tổng quan Java

- **1991**: Sun Microsystems phát triển, tên ban đầu là **Oak** (cho môi trường nhúng)
- **Java 1.x**: Slogan *"Write Once, Run Anywhere"*, dùng cho Web applets (chậm)
- **Java 2 (1.2–1.4)**: Nhanh hơn, chia 3 nền tảng: **J2ME, J2SE, J2EE**
- **Java 5–8**: Cải tiến liên tục về hiệu năng và tính năng

---

## 2. Cơ chế Biên dịch & JVM

```
Mã nguồn (.java) → javac → Bytecode (.class) → JVM → Thực thi
```

| Khái niệm | Giải thích |
|---|---|
| **Bytecode** | Độc lập nền tảng, không phải mã máy |
| **JVM** | Phụ thuộc OS/hardware, thực thi bytecode |
| **JRE** | JVM + thư viện runtime |
| **JDK** | JRE + javac + javadoc + jdb +... |

> *"Write Once, Run Anywhere"* vì bytecode chạy được trên mọi JVM, không cần biên dịch lại.

## 4. Cấu trúc chương trình Java

- Tập hợp các **lớp (class)**, mỗi lớp một file `.java` (trùng tên)
- Điểm vào: `public static void main(String[] args)`

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, world");
    }
}
```

**Biên dịch & chạy:**
```
javac HelloWorld.java   → tạo HelloWorld.class
java HelloWorld         → thực thi
```

## 5. Lập trình Hướng đối tượng (OOP)

### Tam giác P.I.E

| Trụ cột | Nghĩa |
|---|---|
| **Polymorphism** – Đa hình | Đối tượng có thể tồn tại ở nhiều dạng |
| **Inheritance** – Kế thừa | Lớp con kế thừa thuộc tính & hành vi lớp cha |
| **Encapsulation** – Bao gói | Gom dữ liệu + phương thức, che giấu chi tiết cài đặt |

Ngoài ra: **Abstraction (Trừu tượng hóa)** – mọi thứ đều là đối tượng.

---

### 5.1 Đối tượng (Object)

Mỗi đối tượng có 3 thành phần:
- **Trạng thái** – giá trị các thuộc tính (field)
- **Hành vi** – các phương thức (method)
- **Định danh** – duy nhất, dù 2 đối tượng cùng trạng thái vẫn khác nhau

```java
Date today = new Date();   // tạo đối tượng trên Heap
today.setDate(2, 9, 2020); // gửi thông điệp
```

### 5.2 Lớp (Class)

> Lớp là **khuôn mẫu** (blueprint) để tạo đối tượng.  
> Quan hệ: **Lớp ↔ Kiểu dữ liệu**, **Đối tượng ↔ Biến**

### 5.3 Thông điệp (Message)

```java
today.setDate(2, 9, 2020);
//  ↑ đối tượng đích   ↑ tên phương thức   ↑ tham số
```

Thông điệp = cách đối tượng A yêu cầu B thực thi hành vi.

### 5.4 Kế thừa

- Quan hệ **"is-a"**
- Lớp dẫn xuất (derived) kế thừa từ lớp cơ sở (base)
- Tái sử dụng giao diện & cài đặt

### 5.5 Đa hình

- Các đối tượng lớp khác nhau nhận **cùng thông điệp** nhưng xử lý **khác nhau**
- VD: `draw()` trên `Rectangle` vs `Triangle` → kết quả vẽ khác nhau

## 6. Python vs Java (so sánh nhanh)

| Đặc điểm         | Python                   | Java                        |
| ---------------- | ------------------------ | --------------------------- |
| **Kiểu dữ liệu** | Dynamic (`x = 10`)       | Static (`int x = 10`)       |
| **Thực thi**     | Thông dịch (interpreted) | Biên dịch → bytecode (JVM)  |
| **Bộ nhớ**       | Ẩn, tự động              | Tường minh: Stack vs Heap   |
| **Cấu trúc**     | Indentation              | `{}` + bắt buộc trong Class |
| **Ưu tiên**      | Tốc độ viết code         | Bảo trì & Scale             |
