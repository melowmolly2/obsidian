## What is software testing?
- Software testing is a systematic process of executing and evaluating software to: 
	- Detect defects and unexpected behavior
	- Verify compliance with specified requirements
	- Reduce the risk of failures in production
## Testing levels
- Software testing is performed at multiple levels, progressing from individual components to the complete system
	- Unit testing
		- Tests individual units or components in isolation
	- Integration testing
		- Tests interactions between combined units
	- System testing
		- Tests the entire integrated system as a whole
	- Acceptance testing
		- Validates the system from the user or business perspective
## Unit testing
- Verify the correctness of the "smallest" testable unit of software
	- Tested unit: typically a single class or individual methods
- Units are tested independantly of other components
	- Interactions with external classes or services are mocked or stubbed
- Test inputs: Method invocations with controlled parameters
- Test oracle: assertions on 
	- Returned values
	- Object state
	- Thrown exceptions
