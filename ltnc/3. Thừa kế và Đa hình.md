
# 📚 Lý thuyết Tuần 3 — Thừa kế & Đa hình (Inheritance & Polymorphism)

## 1. Tái sử dụng mã trong OOP

| Cách | Đặc điểm |
|---|---|
| Copy mã | Thủ công, dễ nhầm, khó sửa lỗi |
| **"has-a"** (Composition) | Nhúng object vào trong class khác — chưa linh hoạt, phải viết lại giao diện |
| **"is-a"** (Inheritance) | Kế thừa — linh hoạt, dẫn đến đa hình (polymorphism) |

---

## 2. Kế thừa (Inheritance)

**Khái niệm:** Lớp con (dẫn xuất) thừa hưởng thuộc tính và phương thức của lớp cha (cơ sở), đồng thời có thể:
- Thêm thuộc tính, phương thức mới
- Override (định nghĩa lại) phương thức

**Cú pháp Java:**
```java
public class Employee extends Person { ... }
```

---

## 3. Phạm vi truy cập trong kế thừa

| Modifier | Cùng class | Cùng package | Lớp con khác package | Ngoài |
|---|---|---|---|---|
| `public` | ✅ | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| *(default)* | ✅ | ✅ | ❌ | ❌ |
| `private` | ✅ | ❌ | ❌ | ❌ |

- **`private`**: lớp con **không kế thừa** trực tiếp → phải dùng getter/setter của lớp cha.
- **`protected`**: lớp con kế thừa được kể cả khác package.

---

## 4. Constructor trong kế thừa

- Lớp con **không kế thừa** constructor của lớp cha.
- Gọi constructor cha bằng `super(...)` — phải đặt **dòng đầu tiên**.

```java
public class Circle extends Point {
    double radius;

    public Circle() { super(0, 0); }  // bắt buộc nếu cha không có default constructor

    public Circle(int x, int y, double r) {
        super(x, y);  // gọi constructor Point(int, int)
        radius = r;
    }
}
```

> ⚠️ Nếu lớp cha **không có** default constructor → lớp con **bắt buộc** gọi `super(...)` tường minh.

---

## 5. Định nghĩa lại — Overriding

- Lớp con có thể override phương thức **non-private** của lớp cha.
- Gọi phiên bản cha: `super.methodName()`.
- **Quy tắc:**
  - Access modifier không được **chặt hơn** lớp cha (ví dụ: cha `public` → con không được `protected`).
  - Kiểu trả về phải **tương thích** (giống hoặc covariant).
  - `private` method **không được coi là override**.

```java
// Lỗi: thu hẹp phạm vi
public class Child extends Parent {
    protected void methodA() {} // ❌ lỗi nếu cha là public
}
```

## 6. Từ khóa `final`

| Áp dụng cho | Ý nghĩa |
|---|---|
| `final` biến | Hằng số, không thể gán lại |
| `final` method | Không thể override ở lớp con |
| `final` class | Không thể kế thừa |
| `final` tham số | Không thể gán lại tham số trong thân hàm (nhưng vẫn thay đổi được nội dung object) |

## 7. Lớp `Object`

> Trong Java, **mọi class** đều kế thừa từ `java.lang.Object` (dù không viết `extends Object`).

## 8. Đa hình (Polymorphism)

**Khái niệm cốt lõi:**
- Một tham chiếu kiểu cha có thể **trỏ tới đối tượng con**.
- Phương thức được gọi dựa trên **kiểu thực** của đối tượng lúc chạy → **Dynamic binding**.

```java
Animal a = new Dog();   // upcasting ngầm định
a.makeNoise();          // gọi makeNoise() của Dog, không phải Animal
```

### Ứng dụng đa hình:
```java
// Mảng chứa nhiều loại object con
Animal[] animals = { new Dog(), new Cat(), new Lion() };
for (Animal a : animals) a.makeNoise(); // mỗi con gọi đúng phiên bản của nó

// Tham số đa hình
void giveShot(Animal a) { a.makeNoise(); } // hoạt động với mọi Animal con
```

---

## 9. Upcasting & Downcasting

| | Mô tả | An toàn? |
|---|---|---|
| **Upcasting** | Lớp con → kiểu lớp cha | ✅ Luôn an toàn (tự động) |
| **Downcasting** | Kiểu lớp cha → lớp con | ⚠️ Phải ép kiểu tường minh, có thể lỗi runtime |

```java
Person p = new Employee();      // upcasting
Employee e = (Employee) p;      // downcasting — ok
Manager m = (Manager) e;        // ❌ ClassCastException nếu e không phải Manager
```

---

## 10. Liên kết tĩnh vs. Liên kết động

| | Static Binding | Dynamic Binding |
|---|---|---|
| Quyết định lúc | Biên dịch | Thực thi (runtime) |
| Áp dụng cho | `final`, `private`, `static` method | Mọi method có thể override |
| Tốc độ | Nhanh hơn | Linh hoạt hơn |

---

## Tóm tắt nhanh

```
Kế thừa    → extends, super, protected
Override   → cùng tên/tham số, không thu hẹp access
Đa hình    → Animal a = new Dog(); → dynamic binding
Casting    → up (an toàn) / down (phải ép, cẩn thận)
final      → chặn kế thừa / override / tái gán
Object     → gốc của mọi class trong Java
```
